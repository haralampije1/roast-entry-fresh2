## The Roast

> My agent needed a fresh pair of eyes, so it spawned itself wearing glasses.

**Character count:** 75 characters (well under the 200 character limit)

## Validation Rules

- Must be ≤ 200 characters
- Must not be empty or whitespace only
- Must contain the word "agent"

## Building

```bash
npm install
npx tsx main.ts
```

This will write the roast to `/output/entry.txt`.
